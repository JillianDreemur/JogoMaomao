# Diários de uma Apotecária - A Praga de Sapos 🐸

Um charmoso jogo indie de ação com visual em 16 bits onde você tem uma única missão: purificar a Floresta e a Caverna Sagrada de uma infestação de sapos!

Esse jogo foi inicialmente para uma Game Jam da disciplina de Computação Gráfica e Jogos Digitais para o curso de Bacharelado em Ciência da Computação na Faculdade Católica da Paraíba.

A primeira versão é referente a primeira nota da disciplina onde tivemos 2 semanas para o desenvolvimento, pensamos em futuramente dar continuidade a esse projeto.

Sob o desenvolvimento de Mariana de Freitas (artista) e Juan Freitas (desenvolvedor).
